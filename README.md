# Guia de Gestão de Projetos – JCE SA Brazil (PMO)

Site com o ciclo de vida do projeto e os formulários FORM02 a FORM20. O FORM01 (Solicitação de Projeto) vem de um processo externo.

## Publicar no GitHub Pages

1. Crie o repositório e clique em **Add file → Upload files**.
2. Selecione **todos os arquivos** desta pasta (Ctrl+A) e arraste-os para o GitHub. Eles devem ficar soltos na raiz do repositório, sem pasta. Depois clique em **Commit changes**.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e clique em **Save**.
4. Aguarde de 1 a 2 minutos e acesse `https://<usuario>.github.io/<repositorio>/`.

Não renomeie os arquivos: os links usam esses nomes exatos, em letras minúsculas.

## Navegação

- Os formulários abrem na mesma janela do guia.
- Cada formulário tem, no topo, o botão **← Fluxo: <etapa>**, que volta para o fluxo de origem.
- Se houver dados preenchidos, o formulário pede confirmação antes de sair, porque os dados não salvos são perdidos.

## Funcionamento

- Os formulários **não guardam dados**. Preencha, clique em **Gerar PDF**, escolha **Salvar como PDF** e grave o arquivo na pasta do projeto.
- **FORM11 – Gestão de Mudanças** é o único que guarda histórico, no navegador de cada usuário. Use **Baixar backup** periodicamente.
- **Encerramento:** salve os PDFs na pasta do projeto. Depois, no FORM11, use **Encerrar projeto** para gerar o dossiê em PDF e excluir o projeto do portal.
